# Workflow: Build Next

Para implementar a próxima tarefa:
1. Leia documentação do projeto (`PROJECT.md`, `DESIGN.md`, `AGENTS.md`).
2. Leia `TASKS.md`.
3. Identifique a próxima tarefa desbloqueada.
4. Implemente somente essa unidade lógica.
5. Rode validações (lint, typecheck, tests).
6. Corrija falhas.
7. Teste manualmente quando houver UI.
8. Atualize `TASKS.md`.
9. Se houver outra tarefa claramente desbloqueada e não existir necessidade de intervenção humana, prossiga.
10. Pare apenas quando houver bloqueio real. Não pergunte "Quer que eu continue?" se o caminho está livre e seguro.
