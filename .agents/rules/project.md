# Regras do Projeto

Antes de trabalhar:
1. Leia `AGENTS.md`.
2. Leia `PROJECT.md`.
3. Leia `TASKS.md`.
4. Leia `DESIGN.md` quando relevante.

Para cada task:
1. Entender a task.
2. Implementar.
3. Validar tipos (`npm run typecheck`).
4. Rodar lint (`npm run lint`).
5. Rodar testes (`npm run test`).
6. Executar aplicação quando necessário.
7. Corrigir problemas encontrados.
8. Atualizar `TASKS.md`.

*Regra de Ouro*: Não marque tarefa como concluída se houver erro conhecido.
